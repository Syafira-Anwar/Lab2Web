Panduan Praktikum HTML Lanjutan

Dokumen ini berisi panduan langkah-demi-langkah pengerjaan praktikum web dasar yang mencakup Semantic HTML, Multimedia (Audio & Video), serta Proyek Mini Form Biodata Mahasiswa.

 Structure Directory Project

Sebelum memulai, siapkan struktur folder dan file pada direktori kerja Anda sebagai berikut:

praktikum-2-html-lanjutan/
├── index.html
├── biodata.html
├── README.md
└── media/
    ├── audio.mp3
    └── video.mp4


Langkah-Langkah Pengerjaan

Langkah 1: Menyiapkan File Multimedia

Buat folder baru bernama media di dalam direktori proyek praktikum-2-html-lanjutan/.

Siapkan file audio bertipe .mp3 dan simpan dengan nama audio.mp3 di dalam folder media/.

Siapkan file video bertipe .mp4 dan simpan dengan nama video.mp4 di dalam folder media/.

Langkah 2: Membuat Halaman Utama (index.html)

Buat file index.html dan gabungkan elemen Semantic HTML serta Multimedia.
